摸鱼日历使用指南

在网页上查假期、算工作日、找拼假方案，也可以让 AI 客户端通过 MCP 查询同一套已核对的假期数据。

用日历网站 接入 AI 客户端

先选假期地区，再安排日期

查看假期和调休
在标题旁切换假期地区，点击日期看详情。选择器会注明适用范围，比如澳大利亚只覆盖新南威尔士州。
找拼假方案、计算工作日
「拼假攻略」展示请几天假能连休多久；还可以计算区间里的工作日，或推算 N 个工作日前后是哪一天。
语言和时钟不改变假期口径
语言只改变界面。时钟默认跟随假期地区，也可单独切换。海外地区可按需打开农历宜忌，它不代表当地假期。

第一次联网打开并成功缓存后，日历可离线查看已缓存的页面和数据，不依赖 MCP 后端。

接入 MCP，让 AI 查假期、算工作日和换时区

MCP 是 AI 客户端调用工具的方式。在支持 Streamable HTTP 的客户端中添加下面的远程地址即可。服务公开、只读，不需要 API Key 或登录。

首选 · Cloudflare Workers https://calendar-mcp-benchmark.calendar-workday-lab.workers.dev/mcp
在 Codex 或 Claude Code 中接入

Codex

codex mcp add moyu-calendar --url https://calendar-mcp-benchmark.calendar-workday-lab.workers.dev/mcp

Claude Code

claude mcp add --transport http moyu-calendar https://calendar-mcp-benchmark.calendar-workday-lab.workers.dev/mcp

查看 Gemini CLI、Cursor、VS Code 等其他客户端的接入方式

list_regions
查看地区、周末规则及已收录年份。
get_holidays
查询指定地区和年份的法定假期、补班日。
count_workdays
计算区间工作日，包含起止两天。
add_workdays
按当地的周末、假期和调休补班规则，往前或往后推算工作日，不计起始日。
convert_timezone
用 Asia/Shanghai 等时区名换算带日期的 ISO 当地时间。遇到夏令时重复时段，须提供与来源时区匹配的 UTC 偏移量；不存在的时间会报错。
get_local_time
一次看最多五个时区同一时刻的当地时间。
suggest_leave_plan
在请假天数预算内，找含法定假期的最长连休方案。
find_meeting_windows
在最多七天内找两到四人在工作日的共同办公时间。不查询个人忙闲，也不会预约会议。

接入后可以试问：「沙特金融机构从 2026 年 9 月 24 日到 27 日有几个工作日？」答案是 2 个。依赖假期数据的工具遇到未收录的年份会报错，不估算；农历宜忌请在网页上使用。

备用 · Render https://moyu-calendar-mcp.onrender.com/mcp

如果 Cloudflare 连不上，可手动替换客户端里的地址。Render 闲置后首次调用可能需要等约一分钟。
